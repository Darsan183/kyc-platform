# KYC Platform Frontend

Enterprise-grade Next.js frontend for the Autonomous Compliance Intelligence Platform.

## Tech Stack
- Next.js 14
- React 18
- TypeScript
- Material UI 5

## Pages
- `/login` - Authentication
- `/dashboard` - Main dashboard with statistics
- `/customers` - Customer management
- `/cases` - KYC case tracking
- `/documents` - Document viewer
- `/risk` - Risk assessment visualization
- `/graph` - Knowledge graph visualization
- `/audit` - Audit reports
- `/monitoring` - Continuous monitoring center

## Features
- Responsive Material UI design
- Redux Toolkit state management
- SWR data fetching
- Type-safe API integration
- Role-based access control

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```
